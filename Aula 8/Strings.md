## Strings
Retorna a quantidade de caracteres da string:
```
str.length()
```
Retorna o caractere na posição indicada:
```
str.charAt(0)
```
Compara o conteúdo de duas strings (não use ==, pois este compara posições de memória):
```
equals(Object another);
equalsIgnoreCase(String another);
```

Retorna o índice da primeira ou última ocorrência de um caractere/substring:
```
indexOf(String str);
lastIndexOf(String str);
```
divide uma string por cada caracter:
```
char [] y = x.toCharArray();
```
coloca uma string em upper case:
```
m = m.UpperCase();
```
coloca um string em lower  case:
```
m = m.LowerCase();
```
retira espaços no começo e fim:
```
m = m.trim();
```
sepera a string em partes com base no separador escolhido
```
String[] partes = str.split("#");
```

## Comandos do ArraList

Para criar uma ArrayList:
```
Array List x = new ArrayList()
```
Comando para adicionar elemento(o indece é definido pela ordem de adição):

```
x.add("casa");
x.add("mesa");
```
Verifica se a List possui um elemento:
```
boolean b = x.contains("casa");
// b = 1
//o .contains realiza o for, fazendo um .equals com todos elementos
```
Retorno do indice de um elemento:
```
int a = x.indexOf("casa");
// a = 0
//
```
